# ✂️ Flappy Barber — אבי × קוקו

משחק ארקייד מקורי למובייל בהשראת משחקי Flappy: בוחרים את אבי או קוקו, מנפנפים בכנפיים ומנסים לעבור כמה שיותר עמודי מספרה בלי להיתקע.

## קישורים

- **משחק:** https://shalevg12.github.io/flappyBarber/
- **שלט QR מוכן להדפסה:** https://shalevg12.github.io/flappyBarber/qr.html

## איך משחקים?

1. בוחרים לשחק עם אבי (ספר הנשים) או קוקו (ספר הגברים).
2. לוחצים על "יאללה, עפים!".
3. בנגיעה הראשונה מתחילים. כל נגיעה נוספת מקפיצה את הדמות למעלה.
4. עוברים בין עמודי המספרה ומנסים להשיג את הניקוד הגבוה ביותר.

במחשב: רווח, חץ למעלה או W. אפשר להשהות את המשחק ולשחק שוב.

## פרטיות ונתונים

אין צורך בהרשמה. השיא של כל דמות והעדפת הצלילים נשמרים רק ב־`localStorage` במכשיר הנוכחי. אין שרת, אין שמירת מספרי טלפון ואין טבלת ניקוד משותפת.

## פרסום

האתר סטטי ואינו דורש תהליך build או התקנת תלויות. להפעלת GitHub Pages: `Settings → Pages → Deploy from a branch → main → /(root)`.

- `index.html` — המשחק המלא, כולל תמונות הפנים השקופות בקובץ עצמו.
- `qr.html` — שלט QR להדפסה, שפועל גם ללא טעינת ספריית QR חיצונית.
