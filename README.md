# ✂️ Flappy Barber — אבי × קוקו

משחק מובייל של המספרה, בהשראת משחקי Flappy Bird. בוחרים את אבי או קוקו, עפים בין עמודי מספרה צבעוניים ומנסים לשבור שיא.

## משחק אונליין

**https://shalevg12.github.io/flappyBarber/**

## איך משחקים?

1. בוחרים את **אבי** (ספר הנשים) או **קוקו** (ספר הגברים).
2. לוחצים על **"יאללה, עפים!"**.
3. נוגעים במסך כדי להתחיל; כל נגיעה נוספת מקפיצה את הדמות.
4. עוברים בין עמודי המספרה בלי לגעת בהם או ברצפה ובתקרה.
5. בכל מעבר מוצלח מקבלים נקודה. לכל דמות נשמר שיא אישי בדפדפן.

המחשב: מקש רווח או חץ למעלה להתרוממות. `Esc` להשהיה.

## קוד QR למספרה

**https://shalevg12.github.io/flappyBarber/qr.html**

אפשר לפתוח את העמוד ולהדפיס שלט A4 עם ברקוד. עמוד ה-QR עובד גם ללא שירות צד שלישי (הקוד מוטמע בו).

## טכני

- משחק סטטי בקובץ `index.html`, HTML/CSS/JavaScript ו־Canvas בלבד.
- הפנים של אבי וקוקו מוטמעות בתוך הקובץ, ללא צורך בשרת או הורדת נכסים חיצוניים.
- שיאים והגדרות צליל נשמרים מקומית במכשיר באמצעות `localStorage`.
- אין חשבונות או שיתוף מידע בין מכשירים.
- מתאים לפרסום ב־GitHub Pages מהענף `main`, התיקייה `/(root)`.

המשחק מקורי ומשתמש במכניקת Flappy הנפוצה, ללא העתקת קוד או גרפיקות של המשחק המקורי.
